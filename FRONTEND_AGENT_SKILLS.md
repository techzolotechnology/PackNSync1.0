## How To Call Them

Installed Codex skills can be called with `$skill-name`, for example:

```text
$frontend-ui-engineering redesign the PackNSync dashboard and verify desktop/mobile layout.
```

These internet skills are currently saved as references, so call them like this:

```text
Use the saved `frontend-ui-engineering` skill from `external-frontend-agent-skills` to improve the PackNSync registration page.
```

```text
Use the saved `shadcn-ui` and `tailwind-css` skills from `external-frontend-agent-skills` to rebuild this modal.
```

```text

```

To make one permanently callable as `$skill-name`, ask:

```text

```
