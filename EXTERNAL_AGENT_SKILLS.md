```text

```

```text
$expo-router add a native app navigation flow for login, trips, rentals, and profile.
```

```text
$react-native-best-practices review the mobile app for performance and UI jank.
```

```text
$eas-app-stores prepare the Android and iOS store build checklist for PackNSync.
```

```text
$android-cli help build and test the Android project.
```

```text
$swiftui-pro build the iOS SwiftUI screen.
```
